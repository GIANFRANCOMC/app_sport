# 05 - Home: mejoras pendientes

## Pendiente de evaluar

- Orden personalizado de favoritos por usuario.
- Restricción única de base de datos para una preferencia activa por usuario y slug.
- Pruebas automatizadas de autorización multiempresa y consolidación de preferencias.
- Auditoría gradual de ortografía y tooltips en los demás módulos.
- Extracción del menú global de favoritos a un partial Blade si la navbar incorpora más herramientas.
- Internacionalización de la configuración textual cuando System admita más idiomas.

## Criterio

El orden manual debe implementarse únicamente cuando la cantidad de favoritos haga insuficiente el orden actual por secciones. Las mejoras ya implementadas se documentan directamente en `docs/System/modules/01_home.md`.
